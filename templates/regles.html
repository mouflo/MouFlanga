Un profil refuse les torrents qui ne respectent pas ses conditions, et donne des points à chaque format reconnu. Comme dans Sonarr, un seul profil sert pour une série : celui qui la nomme, sinon le profil général (sans série). Sans série indiquée, il vaut pour toutes les séries. Les conditions « doit contenir » se valident si le titre contient au moins un des mots ; « ne doit pas contenir » refuse le torrent dès qu'un mot est présent. Ne compte pas les majuscules.

Un format personnalisé reconnaît un genre de torrent grâce à des conditions (mot dans le titre, équipe, indexeur, taille…). Chaque condition peut être obligatoire (elle doit être vraie) ou inversée (elle doit être fausse). Sans condition obligatoire, il suffit qu'une condition soit vraie. Les points du format se règlent par défaut ici, et peuvent changer dans chaque profil. Les torrents avec le plus de points passent en premier ; un score négatif les fait descendre.

🔑 Google Books

Quand une série est ré-identifiée (menu ⋯ → 🔄 Relancer l'identification), MouFlanga interroge aussi MangaUpdates (sans clé) et Google Books : éditeur, auteur et nombre de tomes. Google Books demande une clé API gratuite : Google Cloud → Bibliothèque d'API → activer « Books API », puis Identifiants → Créer une clé d'API.

Clé actuelle : {{ cle_gb if cle_gb else 'aucune' }}. La clé n'est jamais réaffichée en entier.

« Tester » vérifie la clé auprès de Google sans rien enregistrer. « Enregistrer » ne garde qu'une clé acceptée.

🤖 Claude (sommaires stylisés)

Facultatif et payant (quelques centimes par tome). L'appli lit d'abord le sommaire d'un tome avec la reconnaissance de texte du serveur (gratuite). Quand elle n'y arrive pas (sommaire très stylisé, texte blanc sur noir comme Bakuman), elle peut envoyer les premières pages, réduites, à Claude pour les lire. Clé à créer sur console.anthropic.com → API Keys.
